# Frontend Harness Rules (`apps/web`)

本目录下的所有规则文件都适用于 `apps/web`。新增前端规则时直接在此目录新增 Markdown 文件即可。

## 当前规则

- 所有公共处理函数必须放在现有的 `utils` 目录中；新增前先搜索并复用已有工具函数，禁止创建重复的工具方法。
- 单个组件代码量不得超过 400 行。超过时必须拆分组件、子组件或逻辑模块后再提交。
- 单个方法代码量不得超过 100 行。超过时必须优化并抽取方法，使每个方法保持在 100 行以内。

## 修改前检查

- 搜索 `apps/web/src/utils` 及相关模块，确认没有可复用的同类方法。
- 检查目标组件和方法的行数，提前规划拆分或抽取。
- 修改后重新检查行数，并运行适用的 lint、typecheck 或 test 命令。
