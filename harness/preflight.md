# Code Change Preflight

在写代码前必须完成以下检查：

- 明确本次修改涉及的应用目录和文件范围。
- 如果涉及 `packages/videoPlayer`，先读取 `video-player-sdk.md` 并向用户确认，未确认不得开始编码。
- 读取本目录中与目标目录匹配的规则目录下的全部规则文件；规则文件可持续新增，不需要修改总入口。
- 检查是否已有可复用的公共函数、类型或组件，避免重复实现。
- 如果修改 `apps/server` 且涉及数据库字段、模型 schema、迁移、索引或持久化结构，立即暂停并向用户申请审批；未获明确批准不得编辑相关代码。
- 修改完成后，按对应规则执行必要的静态检查或测试。
