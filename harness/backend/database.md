# Database Change Approval

凡是添加数据库字段的行为，都必须经过用户审批。以下情况均视为数据库字段变更：

- 在 Mongoose schema、ORM model 或数据库实体中新增字段；
- 新增或修改数据库迁移、索引、约束或持久化结构；
- 修改会导致数据库新增持久化属性的写入逻辑。

发现上述行为时，必须在写代码前暂停并向用户说明拟变更的字段、用途和影响，等待用户明确批准。没有明确批准时，不得修改相关文件或以临时字段绕过审批。

## 修改前检查

- 搜索现有 schema、model 和 migration，确认是否能复用已有字段。
- 判断本次改动是否会改变持久化结构。
- 若会改变，先申请审批；若不会，继续遵循项目现有后端规范。
